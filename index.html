安装到桌面

像 App 一样全屏使用

安装后可以全屏打开，页面资源会缓存到本机，断网也能用。安卓 Edge / Chrome / 三星浏览器支持原生安装；iOS Safari 需要手动「添加到主屏幕」。夸克等浏览器一般只能创建网页快捷方式，建议复制链接用 Edge 打开后再安装。

添加到主屏幕需要 HTTPS 访问（本地 localhost 预览也可以）
