# 计划陪伴 · 专注与任务

一个有人陪着的专注计时 + 任务管理小应用。纯静态、无构建工具、无外部 CDN，所有资源在本地。
数据只存在当前浏览器的 localStorage，没有账号，也不会上传任何服务器。

## 目录结构

```
plan-companion/
├── index.html              入口页面
├── manifest.webmanifest    PWA 清单
├── sw.js                   Service Worker（预缓存 / 离线）
├── styles.css              基础样式、布局、通用组件
├── scene.css               陪伴画面（卡面 / 视频）与光影动效
├── views.css               计时 / 任务 / 统计 / 记录 / 设置
├── store.js                数据模型与 localStorage
├── timer.js                专注钟（时间戳计时）
├── scene.js                陪伴画面切换、缩放平移、台词与语音
├── tasks.js                任务、分类、目标
├── stats.js                统计、饼图、日历、记录
├── music.js                背景音乐（循环、淡入淡出、duck）
├── settings.js             设置页
├── app.js                  导航、快捷键、提示音、PWA 安装
├── assets/                 陪伴素材（卡面 / 视频 / 封面 / 缩略图 / 背景音乐）
└── icons/                  本地 PNG 图标（192 / 512 / maskable / apple-touch）
```

## 专注钟与时长

- **三种时长各自独立**：专注、短休息、长休息分别设置，互不影响；「每几个番茄进长休息」也保持可调。
- **在专注页就能改**：点表盘下方的「专注时长 / 短休息时长 / 长休息时长」抽屉，
  有 10/15/20/25/30/45/60 分钟快捷预设和滑杆（专注 1~180、短休息 1~60、长休息 1~120）；
  也可以在「设置 → 计时」里改。
- 空闲时改完会**立即显示在表盘上**，并从下一次开始生效；本段正在进行（包括暂停中）时，
  时长控件会锁定并给出提示，设置页的改动会从下一段开始生效，不会悄悄不生效。
- **正计时**：专注阶段从 0 往上累计、没有上限，点计时器旁的 ⏹（或暂停弹窗里的「结束本轮」）
  才按实际时长结算；暂停期间不计时，继续后接着累计。正计时不显示剩余时间，也不受专注时长设置限制；
  休息阶段仍按各自的休息时长倒计时。

## 陪伴素材说明

- 陪伴画面来自《恋与深空》黎深的**官方卡面截图**与两段短视频，**仅限个人自用**。
- 若要公开部署，建议使用私有方式（如带访问控制的托管、仅自己可见的仓库），
  或直接删除 `assets/` 下的素材并改用自己拥有版权的内容。
- 素材文件都改成了纯英文短名，避免中文 / emoji 文件名在托管与 Service Worker 缓存里出问题。
- 两张卡面与视频封面、缩略图会进 Service Worker 预缓存，保证离线也能看到画面；
  两段视频**不**预缓存，第一次播放时按需缓存，避免首次安装体积过大。离线且未缓存过视频时，
  会自动显示封面帧，点一下即可尝试播放。

## 背景音乐

- 音源：`assets/bgm-calm.mp3`（2 分 43 秒，192kbps 立体声，约 3.9MB）。
  原文件首尾各有约 0.75s 静音，已裁掉多余部分并做 **1.8s 淡入 / 淡出**，循环时不会断层。
- **默认开启，默认音量 30%**（可在设置 → 背景音乐里改成 0~100）。
- **不会自动播放**：浏览器不允许，需要先点一次「开始专注」，或点设置里的音乐开关 /
  陪伴页的小喇叭，之后会按记住的设置继续。
- 专注 ↔ 休息切换时有 0.6s 的柔和过渡；陪伴语音说话时音乐自动压低（duck），说完恢复。
- 页面隐藏、切到别的 tab、锁屏时暂停；回来若原本在播就继续（被拦截则静默，不弹错）。
- 与视频互不干扰：视频本身静音，音乐独立播放。
- 音乐文件**不进** Service Worker 预缓存（避免安装包过大）。首次播放成功后会在后台补一次
  完整请求写入运行时缓存，之后可离线听；若从未联网加载过就离线打开，开关会置灰并提示
  「需要联网加载一次」。


## 本地预览

PWA 的安装与离线缓存需要 HTTP(S) 环境，不能直接双击 `file://` 打开验证。
在本目录执行任意一个静态服务器即可：

```bash
# 方式一：Python（推荐，自带）
python -m http.server 8080

# 方式二：Node
npx serve .
```

然后访问 <http://localhost:8080/>。`localhost` 被视为安全上下文，可以正常注册 Service Worker。

用 Edge 打开本地预览（Windows）：

```bash
start msedge http://localhost:8080/
# 或
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" http://localhost:8080/
```

> 直接双击 `index.html` 也能使用计时、任务与统计，但浏览器不会启用 Service Worker，
> 因此没有离线缓存，也无法“安装到桌面”。

### 在 Edge 里检查 PWA 是否就绪

1. 打开页面后按 `F12` → Application（应用）面板。
2. 左侧 Manifest：应显示名称「计划陪伴 · 专注与任务」、`standalone`、192/512 与 maskable 图标，且没有红色错误。
3. 左侧 Service Workers：状态应为 `activated and is running`，Scope 为站点根路径。
4. 地址栏右侧出现安装图标（或 `⋮` → 应用 → 「安装此站点」），说明可安装。
5. 在 Network 面板勾选 `Offline`，刷新页面：应用仍能完整打开。


## 部署到静态托管

整个 `plan-companion` 目录就是站点根目录，所有引用均为相对路径（`./`），
可以直接放到子路径下（例如 `https://name.github.io/plan-companion/`）。

### GitHub Pages

1. 新建仓库，把本目录全部文件提交到默认分支。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`。
3. 分支选 `main`，目录选 `/ (root)`，保存。
4. 等待一分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

### Cloudflare Pages

1. 打开 Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git。
2. 选择仓库；构建命令留空，输出目录填 `/`（或本目录所在路径）。
3. 部署完成后使用分配的 `*.pages.dev` 域名访问。

### Netlify

1. New site from Git，或直接把整个目录拖进 Netlify Drop。
2. Build command 留空，Publish directory 填 `.`。
3. 部署完成后访问分配的域名。

> 注意：必须通过 **HTTPS** 访问（localhost 除外）才能安装与离线缓存。
> 自定义域名请在托管平台开启 HTTPS。

## 在手机上安装

### 安卓（Edge / Chrome / 三星浏览器）

1. 用手机浏览器打开部署好的 HTTPS 地址。推荐 **Edge 手机版**，其次是 Chrome、三星浏览器。
2. 首次打开约 4 秒后会出现一条很轻的「添加到桌面」提示，点「安装」；
   也可以点右上角 `⋮` → 「安装应用」/「添加到主屏幕」。
3. 系统会弹出安装确认框，点「安装」/「添加」。
4. 从桌面图标打开，即以 `standalone` 全屏模式运行，不显示地址栏。

> 夸克等第三方浏览器通常只能创建「网页快捷方式」，点开后仍是带地址栏的浏览器页面，
> 不会真正以独立 App 安装。遇到这种情况：复制网址 → 用 Edge 手机版打开 → 再按上面的步骤安装。

### iPhone / iPad（Safari）

1. 用 Safari 打开 HTTPS 地址。
2. 点底部「分享」按钮 → 「添加到主屏幕」→ 添加。
3. 从桌面图标打开即可全屏运行。

### 桌面（Edge / Chrome）

1. 用 Edge 打开 HTTPS 地址（本地预览用 `http://localhost:8080/`）。
2. 点地址栏右侧的安装图标（显示器 + 箭头），或 `⋮` → 应用 → 「安装此站点」。
3. 在弹窗里点「安装」，之后从桌面 / 开始菜单打开，就是独立窗口。

安装后页面资源会缓存到本机，断网也能打开；`manifest` 中的图标包含
`purpose: maskable` 版本，适配安卓的圆形 / 方形裁切。

## 更新与缓存策略

- `sw.js` 顶部的 `VERSION` 是缓存版本号；修改任何前端文件后，把它改成新值再部署。
- 新版本安装完成后不会强行打断当前使用，页面右下角会提示「有新版本可用」；
  点「刷新」后新 Worker 接管并重载页面。
- 激活阶段会删除所有旧版本 `plan-companion-*` 缓存，避免长期卡在旧版本。
- 导航请求采用网络优先、断网回退缓存页面；其余静态资源缓存优先并在后台更新。

## 数据说明

- 所有任务、专注记录、分心记录、设置都保存在 `localStorage` 的 `plan-companion.v1` 键中。
- 清除浏览器站点数据会一并删除；应用内「设置 → 清空所有数据」也可以手动清空。
- 「载入示例数据」只在本机写入一批标注用途的演示记录，方便预览统计图表，可随时清空。
- 没有账号、没有排行榜、没有联机自习室。
